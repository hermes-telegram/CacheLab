شروع کار با recall

با یک دکوریتور ساده، نتایج توابع را با TTL، رفتار LRU و پشتیبانی از چندین Backend کش کنید. 

from recall import cache

@cache(ttl="1h", maxsize=1000)
def get_user(user_id):
    return db.query(user_id)

# First call: 2 seconds
result = get_user(42)
# Next call: instant ⚡
result = get_user(42)

پشتیبانی از:

  • Memory Backend (پیش‌فرض)
  • Disk Backend + رمزنگاری AES-256
  • Redis با Connection Pooling
  • Multi-Tier (L1 → L2 fallback)
  • TTL شیء‌TTL شیء Like "1h", "30m"
  • LRU Eviction
  • Sliding TTL
  • Stampede Protection
  • Background Refresh
  • Compression (zlib)
