📖 شروع کار

در چند خط

example.py
# نصب
pip install recall-cache

from recall import cache

@cache(ttl="1h", maxsize=1000)
def get_user(user_id):
    return db.query(user_id)

# اولین فراخوانی: ~2 ثانیه
result = get_user(42)
# فراخوانی بعدی: فوری! ⚡
result = get_user(42)

# مدیریت کش
get_user.cache_clear()
get_user.cache_delete(42)
get_user.cache_set("custom", 99)

# آمار و مانیتورینگ
stats = get_user.cache_stats
print(f"Hit rate: {stats.hit_rate}")

🧠

Memory Backend

LRU eviction, thread-safe, TTL, compression — برای کش درون‌‌حافظه‌ای با بالاترین سرعت. پیش‌فرض دکوریتور @cache. سرعت خواندن: ~250,000 ops/s

پیش‌فرض · سریع‌ترین
💿

Disk Backend

ذخیره روی فایل با AES-256-GCM encryption, background cleanup, size limit — برای کش بین restart ها. سرعت خواندن: ~45,000 ops/s

دائمی · رمزنگاری
☁️

Redis Backend

Connection pooling, retry logic, pipeline, SCAN, cluster mode, key hash — برای سرورهای توزیع‌شده. سرعت خواندن: ~120,000 ops/s

توزیعه · Cluster
🏗

Multi-Tier Backend

L1 (Memory) + L2 (Disk/Redis) با fallback خودکار, TTL jitter, backfill خودکار — بهترین performance برای دیتای بزرگ. سرعت خواندن: L1 ~250K, L2 ~45K ops/s
