# بنچمارک

## اجراز بنچمارک

```bash
curl -X POST http://localhost:5000/api/benchmark/run \
  -H "Content-Type: application/json" \
  -d '{"size": 1000}'
```

## عملکرد معمول

| بک‌اند | خواندن (ops/s) | نوشتن (ops/s) |
|---|---|---|
| حافظه | ~500,000 | ~250,000 |
| حافظه + فشرده‌سازی | ~250,000 | ~125,000 |
| Redis (محلی) | ~120,000 | ~100,000 |
| دیسک (SSD) | ~45,000 | ~35,000 |
